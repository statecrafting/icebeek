# Automation

<!-- Normative authority: specs/005-automation-control-plane/spec.md -->

You are not a foreman. You are the Architect: you write the rules, the
ship obeys them.

- **Drones.** Repair drones patrol the zones you assign, eating struts
  from your production line. Logistics drones carry what belts cannot
  reach. Crawler rovers deploy on expeditions. No moods, no needs:
  only uptime, capacity, and maintenance cost.
- **Logic gates.** Resource flow runs on rules you author: *IF engine
  fuel < 20%, DIVERT all carbon to Refinery; ELSE DIVERT to Storage.*
  Rules are deterministic: the same state always produces the same
  factory behavior.
- **Hull integrity.** The deeper the wastes, the harder the ice
  squeezes. Stress is tracked per hull node; impacts spike it. Struts
  must be manufactured, staged, and delivered continuously, because a
  breach that reaches your automation takes the repair system down
  with it.
- **Mass is the tax.** Every module and stockpile adds weight; weight
  demands torque; torque burns fuel. A bloated ship pays for its
  sprawl on every meter of ice. Lean layouts win; jettisoning cargo
  overboard is a real, painful lever.
